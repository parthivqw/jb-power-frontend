# 00 Project Context

This is the canonical source of truth for the JB Power V1 build. Read this first to orient yourself before diving into the architectural or implementation documents.

**Project**
JB Power

**Business**
Residential & Commercial Solar Installation (On-grid, Off-grid, Hybrid, 3-Phase). End-to-end service including government subsidy assistance.

**Primary Goal**
Generate qualified WhatsApp enquiries from homeowners.

**Target Users**
Property owners reacting to summer electricity bill shock or PM Surya Ghar subsidy announcements.

**Design Inspiration**
Tata Power (for trust and longevity), but executed with the agility and approachability of a local expert.

**Competitors**
ZunRoof (zunsolar), Loom Solar.

**Current Phase**
Frontend V1 Implementation.

**Tech Stack**
React + Vite + TailwindCSS. (No backend, no FastAPI, no complex state management for V1).

**Current Blockers (Required from Founder)**
*   High-res Logo
*   Real Installation Photos
*   Official WhatsApp Number
*   2-3 Customer Testimonials
*   Confirmation of MNRE Empanelment / Subsidies

**Success Metric**
The founder can open it in a browser, recognize it as an authentic representation of their business, and say: *"This is exactly what I imagined."*
